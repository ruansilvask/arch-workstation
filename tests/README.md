# Tests

The test suite validates the target environment instead of merely checking
whether package names appear in the package database.

Planned/implemented areas:

- UEFI
- target disk
- protected disks
- CPU
- RAM
- AMD GPU
- AMDGPU/Mesa/RADV
- Vulkan
- Btrfs
- systemd-boot
- NetworkManager
- PipeWire
- Bluetooth
- Zsh
- SSH
- Distrobox
- Steam
- Proton
- DXVK/VKD3D prerequisites
- Gamescope
- MangoHud
- GameMode
- Protontricks
- game library boundary
